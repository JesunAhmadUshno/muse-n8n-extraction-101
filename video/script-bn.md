# SCRIPT (BN): "Muse Potential Extraction 101" (Bangla production)
Production: muse-n8n-extraction-101-2026-10-19 | Version BN | Status: DRAFT for Jesun storyboard gate (no generation before the gate)
NOTE ON INDEPENDENCE: This is a separate production written from scratch for a Bangla-speaking audience. It is NOT a translation or adaptation of script-en.md. Own hook, own beat order, own presenter energy. Shared locks only: the verified facts (FACT-SHEET.md), the same avatar character hold, the same studio set, Brand Kit v1.1, Pattern 19 grammar at the principle level, no em dash.
ANGLE (BN only): the pocket computer. The English film argues "not a chatbot, a builder." This film starts from the viewer's own phone: the thing in your pocket is a whole cloud computer that takes orders. The bridge (the home PC as a setu, a bridge) is the hero beat and comes early; the three failures are told as a flashback after the win, which is how the story lands in Bangla conversation: result first, struggle second.
RUNTIME TARGET: about 2:06 plan (speech ends at about 2:04; final cut from the animatic word timings)
RATIO: 9:16 vertical master and 1:1 square master, same cut
SET HOLD: same environment as the EN production: Jesun's studio desk set from the 2026-10-18 production (ink black room, desk, wall screen as proof surface, one key light from the upper left, Signal Red the only accent). Character hold: the locked 3D master avatar, same outfit.
CORE LIST (three surfaces, BN arrangement): the 5 connected Google services; the 4 parts of the bridge; the 3 failed routes. Surfaces in this film: the bridge blueprint document and phase sheet (surface 1), the failure flashback sheet paired against them (surface 2), the receipt card (surface 3).
